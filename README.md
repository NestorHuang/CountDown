# 多段倒數計時器

給投影、大螢幕使用的多段倒數計時網頁。單一 HTML 檔，不需要安裝，也不需要網路，用瀏覽器打開 `index.html` 就能使用。

## 功能

- **超大數字**：會依螢幕大小自動縮放，盡量撐滿整個畫面，開始後自動進入全螢幕
- **多段接力**：每段可以設定名稱和時／分／秒，可以上移、下移、複製、刪除
- **預先提醒**：每段可以各自設定「剩下多少時間時先提醒」，到時會響提示音，數字變黃色
- **時間到**：響「嗶嗶 嗶嗶 嗶嗶」，整個畫面閃紅，並顯示已超時多久；畫面停住，等你按空白鍵才進入下一段
- **重複提醒**：時間到後沒人按的話，每隔幾秒再響一次（可以設定，0 ＝ 只響一次）
- **循環**：整套段落可以重複跑好幾輪（例如運動 40 秒＋休息 20 秒，跑 5 輪）
- **聲音**：音量滑桿可以調整，有試聽按鈕；時間到和預先提醒的提示音長度可以分別設定（預設 3 秒）
- **預先提醒聲音**可選：鐘聲「叮—噹」（預設）、柔和單聲「嘟—」、三連音「嘟嘟嘟」、電子「叮咚」。都設計成比「時間到」更低、更慢、聲數更少，一聽就知道是提醒而不是時間到
- **最後幾秒變紅**，最後 5 秒每秒輕響一聲（可以關掉）
- 設定會自動存在這台電腦的瀏覽器裡

## 快捷鍵（計時中）

| 按鍵 | 功能 |
|---|---|
| `空白鍵`／`Enter`／點畫面 | 暫停／繼續；時間到時進入下一段 |
| `→` | 跳到下一段 |
| `←` | 回上一段 |
| `R` | 本段重來 |
| `F` | 切換全螢幕 |
| `Esc` | 回到設定 |

## 備註

- 聲音由瀏覽器即時合成（Web Audio），已經是網頁能輸出的最大音量；要更大聲請調高系統音量或接外接喇叭。
- 計時以實際經過的時間計算，不會因為分頁切到背景而越跑越慢。
